# Build VYBE as an Android APK

This project is configured for Capacitor. The APK is generated by Android Gradle; it is not a web ZIP.

## Build on a computer (Windows / macOS / Linux)
1. Install Node.js 20+ and Android Studio with Android SDK + JDK 17.
2. Extract this project and open a terminal in the project folder.
3. Run:
   ```bash
   npm install
   npm run build
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. In Android Studio, allow Gradle sync. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. The debug APK is usually at `android/app/build/outputs/apk/debug/app-debug.apk`.

## Build without installing Android Studio on your phone
Push the project to a GitHub repository. The workflow `.github/workflows/build-apk.yml` builds a debug APK and uploads it as a downloadable workflow artifact.

## Camera / microphone
Capacitor Android's WebView uses the app's native permissions. Check `android/app/src/main/AndroidManifest.xml` after `npx cap add android` and ensure these are present:
```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
```
The app should request permissions at runtime on Android. If camera permissions do not appear, implement a Capacitor permission prompt or use a native camera plugin. Camera behavior inside a WebView can vary by Android version.

## Important
The APK is an Android shell around the web app. Some browser-specific editing/export behavior may vary inside Android WebView. The music and Latest sections are still demo/local UI, not an online catalog or community service.
